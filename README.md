# MuregiScore Technologies

A responsive, high-performance corporate website presenting **MuregiScore Technologies** as a multi-disciplinary technology solutions umbrella company that builds mission-critical business software, automates operations, integrates mobile payment rails, and delivers tailored digital platforms across Africa.

MuregiScore Technologies is the umbrella enterprise housing six specialized engineering divisions:

## Key Features & Enhancements

### 1. Interactive Liveliness & Modern Animations
- **Ambient Neural/Constellation Mesh Canvas**: Lightweight, 60fps golden particle mesh with cursor attraction, auto-pausing on scroll to conserve battery.
- **Dynamic Metric Counters**: Smooth animated count-up (`06 Divisions`, `99.98% SLA`, `< 800ms M-Pesa Callback`, `0 Timetable Clashes`, `10k+ Records`).
- **Interactive Live Architecture Simulator (`#simulator`)**:
  - *Daraja M-Pesa Rails*: Real-time STK push and sub-second webhook callback ticker.
  - *EduCore Ratiba Solver*: Multi-stream CBC timetable constraint solving simulator.
  - *Core CRM & BullMQ*: Interactive lead pipeline stage advance with background queue worker logs.
  - *Livestock Bio-Tracker*: Dynamic cow pedigree check and daily milk yield bar chart recomputation.
- **Border-Beam Modern Styling**: Rotating conic beam highlights on flagship division cards.
- **Scroll Progress & Back-to-Top Ring**: Slim viewport progress bar paired with an SVG circular progress ring floating back-to-top button.
- **One-Click Copy Feedback**: Direct clipboard copy for email and WhatsApp with floating status toasts.

### 2. Comprehensive SEO (Search Engine Optimization)
- **Metadata**: Full Open Graph, Twitter Cards, canonical URL, author, publisher, and geographical tags for Nairobi, Kenya (`-1.286389;36.817223`).
- **Schema.org Structured Data (JSON-LD)**:
  - `Corporation` / `Organization` schema with regional coverage, contacts, and knowledge entities.
  - `WebSite` schema with publisher metadata.
  - `ItemList` of `SoftwareApplication` entries for EduCore, Core CRM, Ratiba Engine, and Livestock App.
  - `FAQPage` schema for search engine rich answer cards.
  - `BreadcrumbList` schema for hierarchical navigation.
- **Sitemap & Robots**: `sitemap.xml` with image metadata, and `robots.txt` with crawler directives.
- **PWA Manifest**: `site.webmanifest` for installability and responsive app icons.

### 3. Generative AI Engine Optimization (GEO / LLMO / AIO)
- **`llms.txt`**: Standard machine-readable markdown overview for AI search agents (Perplexity, ChatGPT Search, Claude, Gemini).
- **`llms-full.txt`**: Comprehensive architectural, tech stack, and API documentation for LLMs.
- **Technical FAQ**: Dedicated semantic `<details>` accordion answering high-intent questions for prospective clients and AI scrapers alike.

## File Structure
- `index.html` — Landing page with hero, metric ribbon, live architecture simulator, division search, executive scope matrix, live portfolio systems, technical FAQ, and contact CTAs.
- `styles.css` — High-contrast luxury black-and-gold styling, responsive grid, terminal UI, border beams, and interaction states.
- `script.js` — Ambient canvas particle animation, animated metric counters, interactive architecture simulator, real-time division search, scroll progress ring, and clipboard feedback.
- `robots.txt` — Standard search engine and AI agent crawler directives.
- `sitemap.xml` — XML sitemap with priority, change frequency, and image metadata.
- `llms.txt` & `llms-full.txt` — Machine-readable technical specifications for AI engines.
- `site.webmanifest` — Web application manifest for PWA capabilities.
- `assets/` — Brand identity, crest medallions, and favicon assets.
